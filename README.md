# AssistAbility

AssistAbility is an educational and support website designed to help people with disabilities feel included and empowered, and to provide resources for caregivers, educators, and the general public to learn how to assist and interact respectfully.

## Key Features
- Accessible informational pages explaining support strategies and visual aids.
- A resources and request page where users can ask for assistance or guidance.
- Image and video gallery showcasing inclusive practices and examples.

## Site Structure
- `index.html` — Home / landing page.
- `pages/location.html` — Information about service locations and accessibility.
- `pages/request.html` — Form or instructions to request support or services.
- `pages/support-guide.html` — Guides for supporting people with disabilities.
- `pages/visual aids.html` — Visual resources and aids for communication.
- `css/style.css`, `css/style1.css` — Site styling.
- `assets/images/` and `assets/videos/` — Media used throughout the site.

## How to View Locally
1. Open the project folder in your browser or a code editor.
2. Open `index.html` in any modern browser to browse the site locally.
