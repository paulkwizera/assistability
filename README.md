# AssistAbility

AssistAbility is an educational and support website designed to help people with disabilities feel included and empowered, and to provide resources for caregivers, educators, and the general public to learn how to assist and interact respectfully.

## Key Features
- Accessible informational pages explaining support strategies and visual aids.
- A resources and request page where users can ask for assistance or guidance.
- Image and video gallery showcasing inclusive practices and examples.

## Site Structure
- `index.html` — Home / landing page.
- `pages/location.html` — Information about service locations and accessibility.
- `pages/request.html` — Form or instructions to request support or services.
- `pages/support-guide.html` — Guides for supporting people with disabilities.
- `pages/visual aids.html` — Visual resources and aids for communication.
- `css/style.css`, `css/style1.css` — Site styling.
- `assets/images/` and `assets/videos/` — Media used throughout the site.

## How to View Locally
1. Open the project folder in your browser or a code editor.
2. Open `index.html` in any modern browser to browse the site locally.

# Assistability

Assistability is a small informational website created to support people with disabilities, their families, and the wider community. The site shares resources, guidance, and practical tools to make daily life, learning, and community access easier and more inclusive.

## Purpose

- **Support:** Provide clear, accessible guidance and resources for people with disabilities and caregivers.
- **Connect:** Offer a simple way to request help or locate local services.
- **Educate:** Give actionable tips for people without disabilities on how to assist respectfully and effectively.

## Key Features

- **Home page:** Introduces the project and its goals (`index.html`).
- **Request support:** A form and guide for requesting assistance (`pages/request.html`).
- **Location & services:** Information about finding local support and resources (`pages/location.html`).
- **Support guide:** Practical tips, checklists, and advice for caregivers and educators (`pages/support-guide.html`).
- **Visual aids:** Examples and downloadable resources to help with communication (`pages/visual aids.html`).
- **Media assets:** Images and videos used across the site are located in `assets/images/` and `assets/videos/`.

## Project Structure

Root files:

- `index.html` — Site entry point.
- `README.md` — Project overview (this file).
- `LICENSE` — Project license.

Folders:

- `css/` — Stylesheets (e.g., `style.css`, `style1.css`).
- `assets/images/` — Photo and image assets used in pages.
- `assets/videos/` — Video assets.
- `pages/` — Secondary pages such as `location.html`, `request.html`, `support-guide.html`, and `visual aids.html`.

## How to View Locally

1. Open the project folder in your browser file manager.
2. Double-click `index.html` to view the site offline.

Alternatively, run a simple local server (recommended for consistent behavior):

```bash
# Using Python 3 (from project root)
python -m http.server 8000
# Then open http://localhost:8000 in your browser
```

## Accessibility Notes

- Content aims for clear, plain language and readable structure.
- Images should include meaningful alt text; consider reviewing `assets/images/` and adding or improving alt attributes in the HTML files.
- Ensure form controls in `pages/request.html` have associated labels and visible focus styles.

## Contributing

- Keep CSS changes in `css/` and test in multiple screen sizes for responsive layout.
- For accessibility improvements, add notes and pull requests describing the change.
